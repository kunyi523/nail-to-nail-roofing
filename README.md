# Nail To Nail Roofing — unofficial Hamilton pitch sample

A mobile-first one-page website **proposal** for **Nail To Nail Roofing** (also listed as Nail To Nail Roofing Inc / Nail to Nail Roofing) at 13 Merchison Ave, Hamilton, ON L8H 3C8.

**This is not the company’s official website.** It is an unofficial sample prepared as a pitch so the owner can see what a simple site could look like. It is not affiliated with Nail To Nail Roofing, until they say otherwise.

There is no online booking and no online payment on this page. Hours are **not** confirmed from a live Google listing, so this page does not invent them and does not claim 24/7. The CTA is **call Travis for a look / a free estimate**. This page only helps people **call** or **get directions**.

No public email was found. No official Instagram or Facebook page was found. The old domain `nailtonailroofinginc.ca` was dead (500/503) at research time — do not link it as a live site.

Live URL (after Pages is on): [https://kunyi523.github.io/nail-to-nail-roofing/](https://kunyi523.github.io/nail-to-nail-roofing/)

## How to open

The whole site is one self-contained file: `index.html` (CSS is inlined). Open that file in a browser, or visit the Pages URL on a phone.

Optional local server, from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## GitHub Pages

Static files live at the **repository root**. Enable branch-based Pages (same pattern as the JD Barber sample):

1. **Settings → Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **main**, folder: **/** (root)
4. Save

GitHub will serve the site at `https://kunyi523.github.io/nail-to-nail-roofing/`.

Do not add a GitHub Actions workflow for Pages. The owner will use branch-based Pages.
